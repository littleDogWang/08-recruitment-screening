> Read when integrating Support Engineer Screening Interview into another application.

## Baseline Rule

This checkout is the 08-recruitment-screening scenario derivative of the official Agora Next.js voice quickstart. Read its current source before adapting SDK, token or event behavior. Do not generate a replacement integration from memory.

## Adaptation Sequence

1. Run the existing scenario using Node.js 22+, pnpm 9.15.9 and the documented .env.local contract.
2. Verify an actual call before declaring speech success; local contracts alone are not runtime evidence.
3. Map token, invite, stop, RTC join, RTM subscription and toolkit events into the target app's existing owners.
4. Preserve StrictMode initialization, hook-owned cleanup, combined token privileges, UID remap and interrupted turns.
5. The invite body contains `requester_id` and `channel_name`. The invite route configures the longer silence window and LLM history for new sessions.
6. Start with default conversation: Job requirements and interview topics are in the prompt. Candidate answers are summarized verbally; no candidate record is saved.
7. Add only requested business tools, preserving their exact call scope and confirmation semantics. There is no applicant-tracking integration, durable interview record, hiring score, automatic rejection or offer. Candidate statements are not independently verified facts. Sensitive personal characteristics are not interview criteria.
8. Run pnpm run verify and the appropriate separate Docker/live acceptance checks.
